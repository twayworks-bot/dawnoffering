# 🌿 홀리씨즈교회 새벽기도회 순서 슬라이드 생성기
> **Holy Seeds Church Dawn Prayer Slide Generator (Python Web Service)**

구글 드라이브(엑셀 스프레드시트)의 실시간 예배 순서지와 업로드 영상 공유 폴더를 자동으로 크롤링하여 월요일부터 금요일까지의 새벽기도회 예배 순서 슬라이드를 동적으로 생성하는 Flask 기반 Python 웹 애플리케이션입니다.

---

## 🌟 핵심 기능

1. **구글 드라이브 스프레드시트 연동**
   - `.env`에 기입된 주소를 기본값으로 삼아, 실시간 공유 엑셀 데이터를 가져옵니다.
   - `순서표원천` 시트에서 지정된 주차 구분선(예: `2026-09-07 ~ 2026-09-11`)을 기반으로 해당 주간의 데이터 행을 자동으로 추적하는 스마트 주차 파싱 기술이 적용되어 있습니다.

2. **구글 드라이브 음악/영상 폴더 실시간 스크래핑**
   - `영상일정표` 시트에서 해당 주간의 구글 드라이브 업로드 폴더 링크를 자동으로 읽어들입니다.
   - 공유 폴더에 접속하여 실시간 업로드된 미디어 파일 리스트를 크롤링하고, 요일별 패턴(`1.월.`, `2.화.`, 등) 및 `"찬양"` 키워드를 포함하는 파일명에서 순수 찬양 제목을 발라내어 슬라이드에 자동 매핑합니다.
   - 아직 파일이 올라오지 않은 요일은 자동으로 **`"미업로드"`** 상태로 안전하게 표출됩니다.

3. **스마트한 기준 날짜 연산 및 요일 동작 규칙**
   - **평일(월요일~금요일)**을 기준일로 입력하면: 입력한 날짜가 포함된 **당주(월~금)** 슬라이드가 생성됩니다.
   - **주말(토요일~일요일)**을 기준일로 입력하면: 다가오는 **다음 주(월~금)** 슬라이드가 생성됩니다.

4. **사용성 극대화 및 레이아웃 최적화**
   - **URL 숨김 보안**: 원천 구글 시트 주소는 `hidden` 필드로 관리되어 일반 사용자 화면에는 노출되지 않습니다.
   - **인터랙티브 처리 스피너**: "슬라이드 생성하기" 클릭 즉시 골드 컬러 테마의 흐림(Blur) 로딩창이 띄워져 구글 드라이브 데이터 추출 중임을 명확히 인지시킵니다.
   - **인도/안내/방송지원 정렬**: 레이블의 폭을 `90px`로 고정하고 개행 방지(`flex-shrink: 0`) 및 균등 자간 수정을 적용하여 칼같이 곧은 가로선 정렬을 제공합니다.
   - **Prefix 경로 제공**: 전체 웹 서비스가 `/dawn_offering` 프리픽스 경로를 기초로 작동하여 프록시나 외부 서브 도메인 배포 시에도 유연하게 작동합니다.

## 🛠️ 설치 및 요구사항 (Installation)

### 요구사항 (Prerequisites)
- **Python 3.10** 이상 설치 권장
- 인터넷 연결 필수 (구글 드라이브 API 연동 및 크롤링 목적)

### 설치 방법

1. **프로젝트 저장소 다운로드 및 디렉토리 이동**
   ```bash
   cd C:\dev\python\dawn_html
   ```

2. **가상환경(venv) 생성 및 활성화**
   - **Windows** (PowerShell/CMD):
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```
   - **Linux / macOS**:
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **필수 종속성 패키지 설치**
   ```bash
   pip install -r requirements.txt
   ```

## ⚙️ 환경 설정 (Configuration)

프로젝트 루트 디렉토리의 `.env` 파일에 구글 드라이브 원천 주소와 사용할 시트명을 기록합니다. (오타 매칭을 포함하여 유연하게 적용되어 있습니다)

```ini
# .env 파일 예시
GOGOLE_XLSX_URL=https://docs.google.com/spreadsheets/d/1RWKAewSqTB6wVCw_-R86NjoGszd0Y1Sy/edit?usp=drive_link...
XLSX_SHEETNAME="순서표원천"
WORSHIP_MUSIC_SHEETNAME="영상일정표"
```

## 🚀 실행 방법 (Usage)

1. **가상환경이 활성화된 상태에서 웹 어플리케이션 실행**
   ```bash
   python app.py
   ```
   *(개발자 디버그 모드가 활성화된 채로 5000번 포트에서 구동됩니다)*

2. **웹 브라우저에서 접속**
   - **`http://localhost:5000/`**에 접속하면, 지정된 프리픽스 주소인 **`http://localhost:5000/dawn_offering/`**로 자동 리다이렉트 처리됩니다.

3. **예배 순서 슬라이드 생성**
   - 기본 날짜(오늘 날짜를 기준으로 기본 제공) 혹은 임의의 주일/평일 날짜를 지정하고 **"슬라이드 생성하기"**를 누릅니다.
   - 실시간 구글 드라이브 크롤링 및 파싱 작업(로딩 스피너 표출) 후 결과 슬라이드 화면이 자동으로 출력됩니다.

4. **슬라이드 편의 조작**
   - **키보드 조작**: 방향키 `[← / →]` 또는 `[Space]` 바를 누르면 마우스 조작 없이도 편리하게 슬라이드 장(월~금)을 넘길 수 있습니다. (입력 필드에 포커스되어 있는 경우 제외)
   - **PDF 저장 / 인쇄**: 화면 우측 상단의 **[전체 인쇄 / PDF 저장]** 버튼을 클릭하면 불필요한 컨트롤바 레이아웃이 깔끔하게 걷힌 16:9 슬라이드 비율 그대로 전체 요일을 한 번에 PDF로 내보내거나 인쇄할 수 있습니다.

## 🐳 Docker 컨테이너 운영 방법 (Docker Guide)

이 애플리케이션은 완성도 높은 클라우드 배포 및 무중단 배포(Healthcheck)를 지원하도록 설계되었습니다.

### 1. Docker 이미지 빌드
프로젝트 루트 폴더에서 아래 명령어를 실행하여 도커 이미지를 빌드합니다:
```bash
docker build -t dawn-offering-service .
```

### 2. Docker 컨테이너 실행
빌드된 이미지를 포트 5000번에서 `gunicorn` 운영 서버 환경으로 구동합니다:
```bash
docker run -d --name dawn-offering-app -p 5000:5000 dawn-offering-service
```

### 3. 실시간 환경변수 오버라이드 (호스트 주입)
기본 구글 시트 주소나 시트명, 영상일정표 시트명을 동적으로 교체하여 구동하고 싶다면, 컨테이너 실행 시 `-e` 옵션으로 간편하게 호스트 설정을 주입하십시오:
```bash
docker run -d --name dawn-offering-app \
  -p 5000:5000 \
  -e GOGOLE_XLSX_URL="새로운_구글_스프레드시트_엑셀_URL" \
  -e XLSX_SHEETNAME="새로운_예배순서_시트명" \
  -e WORSHIP_MUSIC_SHEETNAME="새로운_영상일정_시트명" \
  dawn-offering-service
```

### 4. 헬스체크 및 실시간 컨테이너 상태 모니터링
도커 엔진이 30초마다 자동으로 `/dawn_offering/api/status` 엔드포인트를 호출하여 상태를 점검합니다:
```bash
docker ps
```
*(성공적으로 구동 시 Status 열에 `(healthy)`로 실시간 확인됩니다)*
